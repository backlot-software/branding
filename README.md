# Backlot Branding Assets

This repository contains the official branding materials for **[Backlot](https://www.backlot.software)**

## Colors and Fonts

- **Fonts** - lowercase Poppins.
- **Pink** - #f90093
- **Green** - #79fe0c
- **Dark** - Use equals for R G and B f.e. #191919 or #000000
- **Light** - Use equals for R G and B f.e. #e8e8e8 or #ffffff

## Usage

These assets are provided for the Backlot community, contributors, and partners. Feel free to use them in projects, blog posts, talks, or documentation related to Backlot — as long as the usage is consistent with our brand and does not imply endorsement where none exists.

Please observe the following guidelines:

- **Do** use the official assets provided here rather than recreating them.
- **Do not** distort, rotate, recolor, or alter the logos and wordmarks.
- **Do not** use the branding in a way that suggests Backlot endorses your product or service without permission.
- **Do not** incorporate the logo or name as part of your own product name, logo, or domain.

## Contributing

Found a missing asset, an outdated variant, or a usage guideline that's unclear? Contributions are welcome! Please open an issue or submit a pull request describing the change and its intended use case.
